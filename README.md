# MásLimp Services

Sitio web de MásLimp Services, empresa de limpieza integral en Concepción, Chile.

- `index.html`: landing principal
- `gracias.html`: página de confirmación del formulario de cotización (Netlify Forms)
- `netlify.toml`: configuración de publicación en Netlify

Producción: https://maslimpservices.cl (hospedado en Netlify)
